# 对象探索设计

## 1. 目标与范围

更新日期：2026-11-05。实现说明见[对象探索实现](对象探索实现.md)，系统约定见[DESIGN.md](../DESIGN.md)。

在左侧功能菜单的“图谱查看”之后增加“对象探索”。以列表浏览知识库已发布索引中的抽取实体，支持类型、名称筛选，以及属性、来源文本和关联对象查看。对象采用既有“名称＋类型”合并结果，同名不同类型独立显示；数量是合并后的对象数量，不是文档中的提及次数，也不等价于现实中经过身份核实的人数。

功能通过数据库读取图谱及来源，不调用文本模型、向量模型或重排模型，不改变索引、检索及问答算法。

## 2. 权限与数据范围

- OWNER、WRITER、READER 均可浏览有权访问的知识库；每个请求重新检查成员权限。
- 首次访问一次捕获 `active_generation_id`，计数、列表和详情均限定同一知识库和已就绪索引代。
- 筛选、翻页、关联对象跳转沿用已捕获索引代。后台切换活动索引时，当前浏览继续使用原快照，点击“刷新”才重新捕获活动代。
- 没有可用索引时提供索引未就绪提示；索引被清理或对象不存在时提示关闭详情、刷新列表；越权请求拒绝访问。

## 3. 页面与交互

页面在宽屏下左右分栏，窄屏下类型区位于列表上方。

| 区域 | 行为 |
| --- | --- |
| 左侧类型列表 | 提供“全部（总数）”及各类型和数量；按类型名称排序；当前选择高亮 |
| 类型计数 | 统计当前快照中的全部对象，不受右侧名称筛选影响；全部数量为各类型数量之和 |
| 右侧查询 | 名称采用忽略大小写的字面子串匹配；支持回车和“查询”按钮；空名称表示不过滤名称 |
| 对象列表 | 显示对象名称、类型、操作；每行操作提供“详情”；不展示关联图 |
| 组合筛选 | 类型精确匹配，名称条件同时生效；切换类型、提交名称及修改每页条数时返回第一页 |
| 分页 | 默认每页 20 条，可选 20、50、100 条；上一页、下一页及筛选结果总数；按名称、类型、ID 稳定排序 |
| 刷新 | 关闭详情，重新捕获活动索引并加载第一页，保留当前名称和类型条件 |

名称中的 `%`、`_` 等字符作为普通文本匹配。筛选条件的类型最多 100 字符、名称最多 512 字符。加载期间禁用重复操作，失败时显示错误并可刷新重试。

## 4. 对象详情

点击行内“详情”打开可关闭的对话框，展示：

1. 对象名称、类型和合并描述。
2. 对象属性表：属性名称、属性类型、属性值。保留数字、布尔、数组和对象等原生 JSON 值，兼容旧属性字符串列表，不将不同属性值相互覆盖。
3. 关联文本：展示与实体 `source_ids` 关联的完整文本块、来源文档名和块序号。通过索引代记录的文档修订关联来源，不使用文档最新修订代替旧快照。共享文本块对应多个文档时，各文档中的出现位置分别列出。
4. 关联对象：展示一跳邻接对象的名称、类型、关系类型和关系描述；覆盖关系任一端的邻接对象。点击关联对象名称，可在同一快照内查看该对象详情。

关联文本和关联对象分别每页 20 条、独立翻页并显示总数，避免一次加载高关联度对象的全部数据。无属性、无来源、无关联时分别显示空状态。

对话框支持 Escape 关闭、Tab 焦点约束及关闭后焦点恢复。文本与属性值以纯文本显示，文档和模型输出中的 HTML 不执行。切换对象、关闭详情、切换知识库及离开菜单时取消相应请求，迟到响应不得污染当前页面。

## 5. 验收要点

- 全部数量等于类型数量之和；同名不同类型分别可查，名称筛选不修改类型计数。
- 组合筛选、空结果、分页和每页数量均可用；刷新后读取新活动代。
- 详情中可查看原生属性、真实来源文本和邻接对象；共享文本的文档关联完整。
- 后台索引切换不混入另一代的计数、详情和来源；跨知识库、撤权及无索引场景有明确结果。
- 只读成员可浏览；无任何模型调用和数据修改。
- 中英文界面、键盘操作和不可信内容按纯文本显示均有测试覆盖。
