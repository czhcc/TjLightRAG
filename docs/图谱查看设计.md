# 图谱查看设计

## 1. 基线与目标

依据 `d65cef8` 的[系统设计](../DESIGN.md)及 D3 图谱代码编写，日期为 2026-11-04。对应[图谱查看实现](图谱查看实现.md)。

在“知识库问答”下方提供独立的“图谱查看”入口，让知识库成员按实体类型和名称查找已发布实体，并逐步探索其关联关系。该功能只读已有索引，不调用文本、向量或重排模型，不提供图谱人工编辑。

## 2. 页面与交互设计

| 区域 | 内容与操作 |
| --- | --- |
| 查询区 | 实体类型下拉框、实体名称输入框、查询按钮 |
| 关联图区 | D3 力导向 SVG，节点显示名称，连线显示关系类型 |
| 图例与统计 | 实体类型颜色、节点数量、关系数量 |
| 视图操作 | 滚轮缩放、拖动画布、拖动节点、放大/缩小、重置视图 |
| 实体详情 | 单击节点后显示名称、类型、描述和属性，提供展开按钮 |
| 状态区 | 加载、无索引、无匹配、无邻居、还有更多邻居及数量限制提示 |

进入页面先读取当前活动索引中的实体类型，不立即加载整个图。类型不选表示全部，名称不填表示不限名称；点击查询可直接浏览限定数量的当前图谱。

名称按忽略大小写的字面子串匹配，`%`、`_` 不作为 SQL 通配符。类型精确匹配；人、地、物、事、网是常见类型，但界面不把类型限制为五类。

## 3. 查询与展开规则

1. 新查询替换当前画布与展开进度，返回匹配实体及这些实体之间的关系。
2. 双击节点展开单跳邻居；聚焦节点后按 Enter、空格，或使用详情中的按钮，具有相同效果。
3. 展开结果合并到原图，节点按实体 ID、关系按关系 ID 去重。同名但类型不同的实体不合并。
4. 邻居查询不继续套用初始名称、类型条件，因此可展开其他类型的真实相邻节点。
5. 邻接关系较多时分页读取，同一节点再次双击继续加载下一页，已全部加载后不重复请求。

| 限制 | 当前设计 |
| --- | --- |
| 单次查询 | 最多 100 个实体、200 条内部关系，超出提示细化查询，不提供查询结果翻页 |
| 单次展开 | 最多 100 条关系，按稳定关系 ID 排序，通过偏移继续 |
| 当前画布 | 最多 500 个节点、1000 条关系；超限拒绝合并并保留原图 |
| 输入 | 名称最多 512 字符，类型最多 100 字符 |

## 4. 数据、一致性与权限

图谱来自已发布索引的实体表和关系表。实体有 ID、名称、类型、描述、属性；关系有 ID、两端实体 ID、类型集合、描述及权重。当前索引关系是无向关系，画布不凭空绘制方向。

新查询单次捕获当前 `active_generation_id`，响应包含 `generationId`。后续展开沿用该代，不因新代激活而混入不同代节点；重新查询才读取当前活动代。如果原代已失效或节点不存在，提示重新查询。

OWNER、WRITER、READER 均可查看自己有权访问的知识库。所有查询和展开均在服务端复核成员权限和索引状态；前端传入的索引 ID 不构成授权。

## 5. 异常、资源与验收

- 没有可用索引时引导先在[文档管理](文档管理设计.md)上传并完成构建。
- 空查询结果显示“没有找到匹配的实体”，孤立节点展开显示无关联节点。
- 网络或权限失败不伪造空图；展开失败保留已显示图谱，允许重试。
- 切换知识库或离开页面中止请求、停止 D3 模拟，迟到结果不能写入新知识库视图。
- 图谱文字使用文本节点，描述和属性按纯文本显示；不执行实体中的 HTML。
- 验收重点：组合筛选、字面名称、同名不同类型、双击分页、去重、索引切换隔离、只读成员访问和撤权后的拒绝访问。
