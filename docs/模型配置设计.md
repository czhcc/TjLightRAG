# 模型配置设计

## 1. 文档基线与目标

编写日期 2026-11-04，依据 `d65cef8` 的[设计基线](../DESIGN.md)及 V12 后的当前配置实现。对应[模型配置实现](模型配置实现.md)。

统一维护文本、向量和重排模型，并按知识库绑定用途。模型调用使用保存的服务地址、模型标识、密钥及参数；不靠全局环境中的模型调用参数替代页面配置。服务端加密主密钥仍属于部署配置，不能下发浏览器。

历史方案中的“用户维护多个配置版本”已被当前配置覆盖更新取代。索引内部仍保留不可变执行快照，以保证旧索引可检索；这不是页面中的配置版本管理。

## 2. 角色及作用范围

| 操作 | 规则 |
| --- | --- |
| 新建、修改、删除、测试模型 | 平台管理员 |
| 打开菜单 | 平台管理员或当前知识库 OWNER |
| 获取安全模型选项 | 知识库成员 API 可读取 ID、名称、类型；不包含连接及密钥信息 |
| 修改模型用途绑定 | 当前知识库 OWNER；仅平台管理员身份不能越过此 OWNER 校验 |
| 绑定范围 | 对整个当前知识库生效，不是为每个成员分别设置 |

平台维护的模型可供不同知识库选择，但每个知识库的用途映射独立，不存在旧全局绑定回退。

## 3. 页面及字段设计

三个标签页分别显示文本模型、向量模型、重排模型列表。管理员每类有新建按钮，每行提供修改、删除和连接测试。新建/修改、删除确认、用途绑定使用对话框。

| 字段 | 规则 |
| --- | --- |
| 配置名称 | 必填，最多 100 字符 |
| 模型类型 | CHAT、EMBEDDING、RERANK；已有模型不能修改类型 |
| 服务地址 | 配置 HTTP/HTTPS 地址；禁止内嵌凭据、查询串、片段及非法端口 |
| 模型标识 | 必填，最多 256 字符，不允许控制字符 |
| API 密钥 | 可空；修改时留空保留旧值，显式清除才删除 |
| 向量维度 | EMBEDDING 为 1～2000；其他类型为 0 |
| 上下文 token | 1024～1000000 |
| 最大输出 token | 64～32000，必须严格小于上下文 token |
| 超时 | 1～120 秒 |
| 扩展参数 | 仅文本模型，JSON 对象，最多 16 KiB，不能覆盖受控字段或包含凭据 |

文本扩展参数可包含 `chat_template_kwargs.enable_thinking=false` 等供应商参数，是否生效取决于供应商协议。普通问答不强制 JSON 输出；索引抽取由系统设置 JSON 对象格式，用户扩展不能覆盖该受控字段。

## 4. 用途绑定

| 用途键 | 所需类型 | 行为 |
| --- | --- | --- |
| extract | CHAT | 索引实体关系抽取 |
| summary | CHAT | 图谱描述摘要；未单独绑定时构建使用抽取模型 |
| keywords | CHAT | 检索关键词；未绑定时沿用该代抽取模型 |
| answer | CHAT | 问答生成和多轮问题补全 |
| embedding | EMBEDDING | 构建索引及该代查询向量 |
| rerank | RERANK | 用户启用后的候选文本重排，可不绑定 |

解绑通过空选项提交。新建知识库不会自动建立用途绑定。用途类型必须匹配，整个绑定更新在事务中执行。

## 5. 保存、测试、删除与索引一致性

- 保存直接修改当前配置，不生成可编辑历史版本。正在构建的索引使用先前捕获的执行参数。
- 测试基于已保存配置发出真实小请求：文本对话、单条向量或单文档重排；返回成功和耗时，不回传供应商完整内容。测试成功不等于真实任务质量或所有长请求都通过。
- 2026-11-06：文本模型测试另外发送无副作用的原生 connection_probe 工具定义，只有真实 tool_calls 才验证通过。界面独立提示工具能力已验证或未验证，普通连通成功不能代表可用于智能体问答。决策调用必须保留配置中的扩展参数。

- 工具能力探针显式指定 tool_choice=required，最多两次验证，始终不执行工具。未验证通过只表示本次探测没有获得合法原生调用，不证明模型绝对不支持工具。正常问答若首轮返回普通文本，应在限额内重试并提示本轮协议未满足，不能直接复用“不兼容”的结论。
- 删除前需解除所有知识库用途绑定。数据库外键冲突时拒绝删除；不能只解除当前知识库却忽略其他知识库绑定。
- 删除当前配置不删除索引执行快照。已有索引查询向量继续使用该代 embedding 快照，避免模型更新破坏旧空间。
- 更换抽取或向量设置后，新的配置通过后续构建生效；旧代不会自动重算为新模型空间。

## 6. 安全与验收

密钥仅经服务端 SecretVault 加解密，列表只返回是否已配置，不返回明文或密文。主密钥缺失时给出部署就绪提示；日志和异常不包含模型请求正文、密钥或供应商原始错误正文。

验收覆盖三个标签、增删改测、输出 token 修改、扩展 JSON 中 `false`/数组等类型保留、密钥保留与清除、跨知识库绑定、角色权限、绑定冲突删除和旧索引空间稳定性。
